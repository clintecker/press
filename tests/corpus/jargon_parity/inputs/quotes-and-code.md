# Quotes, code, and URLs

Here the `seam` in inline code must be hidden, and so must the fenced block:

```
The seam and the gate live in code and must not be flagged.
```

> A quoted seam and a quoted gate are skipped unless --include-quotes is set.

A link to https://example.com/seam/gate must not be scanned, but the plain
seam in this final sentence is a live finding for both checkers.
